# قالبُ صور إذكاء — «التوقيع» (المعتمد)

**الصورةُ كما التُقطت، كاملةً بدقّتها، وفي أسفلها توقيعُ إذكاء — بلا كلامٍ آخر.**

- **الظلّ**: من أسفل الصورة ظلٌّ بلون الليل يتلاشى صعودًا (ثلثُ ارتفاعها)، أرضًا للتوقيع.
- **سطرُ التوقيع**: الشعارُ يمينًا (حيث تبدأ القراءة) ورابطُ **Ethka.sa** يسارًا بخطّ ثمانية، على خطّ أساسٍ واحد
  مع اسم «إذكاء» في الشعار، وحروفُه الكبيرة بارتفاع جسم الاسم.
- **الذكاء**: شدّةُ الظلّ بحسب سطوع أسفل الصورة — يشتدّ على الفاتح ويخفّ على الداكن (بين ‎0.46‎ و‎0.78‎)؛
  والرابطُ يُضبط على خطّ الأساس بالقياس في الصفحة لا بالتقدير؛ ومدٌّ خفيف للمستويات بسقف ١٢٪.

## أنماطٌ أخرى في القالب (للاختيار)

| الطبقة | النمط | الملف | ما هو | الإلهام |
|---|---|---|---|---|
| **الغلاف** | `غلاف` | `src/cover.mjs` | أوّلُ صورة تُرى من **نافذةٍ على شكل معيّن الشعار** على أرض الليل، بخيطٍ ذهبيّ حولها، والشعارُ تحتها على المحور. ‎4:5‎. | الشعارُ إطارًا ونافذة: ICP لبنتاغرام، وBlank Street لوولف أولنز |
| **اللون** | `تذهيب` | `src/sign.mjs` | التوقيعُ نفسُه مع **معالجةٍ لونيّة من الهويّة**: الظلالُ ليل، والأوساطُ ذهب، والأضواءُ كريميّ — تُعرف بها منشوراتُنا ولو حُذف الشعار. لصورةٍ أو صورتين مختارتين. | «Colorizer» لكولينز في هويّة سبوتيفاي |

وتبقى الأنماطُ الأولى للاختيار: `تموج` (`src/frame.mjs`) و`زجاج` (`src/glass.mjs`) و`قصة` (`src/cut.mjs`).

## الاستعمال

```bash
cd صور
npm install                                              # مرّةً واحدة (Playwright)
# ضع الصور في content/photos/ واذكرها في ملف المحتوى، ثم:
node src/build.mjs content/liqa-1.json                   # التوقيعُ المعتمد لكلّ صورة
node src/build.mjs content/liqa-1.json --style غلاف,توقيع # ومعه غلافُ المنشور
```

```json
{
  "meta": { "file": "اللقاء-الافتتاحي", "style": "توقيع" },
  "photos": [
    { "src": "photos/liqa-1-01.jpg" },
    { "src": "photos/liqa-1-02.jpg", "corner": "أعلى-يسار", "veil": 0.7 }
  ]
}
```

ويخرج مع الصور `القرارات.json` بما قرّره النموذجُ لكلّ صورة ولماذا (درجاتُ الزوايا الأربع).

## ما يقرّره النموذجُ وحده

1. **نافذةُ الغلاف**: يُمرَّر مربّعُ الاقتطاع على الصورة، ويُجمع «قناعُ الموضوع» (خريطةُ حدّة: ما في بؤرة العدسة
   حادٌّ وما خارجها ضبابيّ) **داخل المعيّن** لا المربّع — فيقع المتحدّثُ والشاشةُ في قلب النافذة.
2. **ظلُّ التوقيع**: يُقاس سطوعُ الثلث الأسفل من الصورة فتُحدَّد شدّةُ الظلّ الصاعد منه.
3. **زاويةُ الأنماط الأخرى** (التموّج والزجاج والقصّة): الأقلُّ حدّةً والأبعدُ عن الموضوع، و`corner` يتقدّم:
   `أسفل-يمين` · `أسفل-يسار` · `أعلى-يمين` · `أعلى-يسار`.
4. **المستويات**: مدٌّ خفيف حول وسط الصورة نفسِها بسقف ١٢٪.
5. **الدقّة**: التوقيعُ والتذهيبُ بنسبة الصورة ودقّتها الأصليّة (حتى ‎4096‎) بلا قصّ؛ والغلافُ ‎2160×2700‎.

ويخرج مع الصور `القرارات.json` بكلّ قرارٍ ولماذا.

## الهويّة

كلُّ لونٍ من [`../عروض/src/brand.mjs`](../عروض/src/brand.mjs) وكلُّ شكلٍ من الشعار نفسِه
([`../عروض/src/identity.mjs`](../عروض/src/identity.mjs) ← `Logo.tsx`): الذهبُ ‎`#B9933A`‎، والليلُ ‎`#12171E`‎،
والحبرُ «أبيضُ الملف على الداكن». لا نسخةَ ثانيةً هنا تفترق عن الأصل.

## حدودٌ معلنة

- خريطةُ الحدّة تفترض صورةً ذات بؤرة (متحدّثٌ واضح وجمهورٌ ضبابيّ). في الصورة الحادّة كلِّها قد تمسّ أطرافُ
  الحلقات الخافتة الموضوع؛ فاكتب `corner` أو راجِع.
- النموذجُ لا يتعرّف الوجوه ولا يختار أيَّ الصور تُنشر: **راجِع كلَّ صورةٍ بعينك قبل النشر.**
