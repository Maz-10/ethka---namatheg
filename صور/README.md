# قالبُ صور إذكاء — «اللوح»

**الصورةُ مركّبةً في ورق إذكاء كما تُركَّب المطبوعةُ في متحف، بلا كلام.** لا عنوانَ ولا وصفَ ولا تاريخ:
الكلامُ مكانُه نصُّ المنشور والتقرير، واللوحُ يحمل العلامة.

والفكرةُ من فلسفة «المَجمَع الساكن» (`../الفلسفة-المجمع-الساكن.md`): الفراغُ مادّةٌ أولى، والهندسةُ صارمة،
والعلاماتُ مرجعيّةٌ دقيقة، والذهبُ حدثٌ واحد.

| | ما هو |
|---|---|
| **التطويق** | حاشيةٌ من ورق الهويّة (الكريميّ)، والصورةُ فيها بحافّة قطعٍ مشطوفة كتركيب المطبوعات. وحولها طوقٌ من خيطٍ شعريّ في زواياه معيّناتُ الشعار نفسِه (يقف الخيطُ دون كلّ معيّنٍ بفُرجة)، وفي منتصف أضلاعه علاماتُ المحور. |
| **الذهب** | معيّنٌ واحدٌ ذهبيّ في الزاوية العليا اليمنى — حيث تبدأ القراءةُ العربيّة — وذهبُ الشعار. لا ذهبَ سواهما. |
| **الغشاء** | تذهيبٌ خفيف للصورة كما كانت المطبوعاتُ تُذهَّب: الظلالُ تميل إلى ليل الهويّة، والأوساطُ إلى ذهبها، والأضواءُ إلى كريميّها. فتصير صورُ اللقاء كلُّها من نَفَسٍ واحد ولا تفقد ألوانها. |
| **الختم** | الشعارُ في السجلّ تحت الصورة، على محور التناظر، صغيرًا كبطاقة المتحف. |

ونغمتان: **`ورق`** (الأساس) و**`ليل`** (الحاشيةُ بلون الليل والشعارُ أبيض).

## الاستعمال

```bash
cd صور
npm install                                    # مرّةً واحدة (Playwright)
# ضع الصور في content/photos/ واذكرها في ملف المحتوى، ثم:
node src/build.mjs content/liqa-1.json         # ← dist/<meta.file>/<meta.file>-01.jpg …
node src/build.mjs content/liqa-1.json --tone ليل
node src/build.mjs content/liqa-1.json --tone ورق,ليل
```

```json
{
  "meta": { "file": "اللقاء-الافتتاحي", "tone": "ورق" },
  "photos": [
    { "src": "photos/liqa-1-01.jpg" },
    { "src": "photos/liqa-1-02.jpg", "veil": 0.12 }
  ]
}
```

ويخرج مع الصور `القرارات.json` بما قرّره النموذجُ لكلّ صورة.

## ما يقرّره النموذجُ وحده

1. **الصورةُ كاملةٌ أبدًا، والحاشيةُ هي التي تتكيّف.** لا يُقصّ من الصورة شيء: الأفقيّةُ واسعةُ الحاشية العليا
   والسفلى، والطويلةُ تتّسع حاشيتاها الجانبيّتان حتى يبقى اللوحُ ‎4:5‎، والبانوراميّةُ يُزاد في أعلاها وأسفلها حتى
   ‎1.91:1‎ — فيقع اللوحُ أبدًا في حدود إنستغرام وإكس ولينكدإن، ولا تقصّه منصّة.
2. **الدقّة**: اللوحُ بعرض ‎2400‎ بكسل ما سمحت الصورة، ولا تُعرض الصورةُ فيه بأكبرَ من بكسلاتها (الصورةُ الصغيرة
   يصغر لوحُها ولا تتشوّش).
3. **المستويات**: مدٌّ خفيف حول وسط الصورة نفسِها بسقف ١٢٪ — لا يُفتَّح الداكنُ ولا يُغمَّق الفاتح.
4. **شدّةُ الغشاء**: ‎0.16‎ أساسًا، وتزيد حتى ‎0.26‎ بقدر مسحة الصورة اللونيّة (إضاءةٌ صفراء أو زرقاء)، فتتقارب
   صورٌ التُقطت تحت أضواءٍ مختلفة. و`veil` في ملف المحتوى يتقدّم على الحساب.
5. **الهندسةُ من وحدةٍ واحدة**: الحاشيةُ جزءٌ من عرض اللوح، وكلُّ ما سواها (السجلّ، وبُعدُ الطوق، والمعيّنات،
   والشعار) أضعافُها — فيتناسب اللوحُ في كلّ نسبة.

## الهويّة

كلُّ لونٍ من [`../عروض/src/brand.mjs`](../عروض/src/brand.mjs) وكلُّ شكلٍ من الشعار نفسِه
([`../عروض/src/identity.mjs`](../عروض/src/identity.mjs) ← `Logo.tsx`): حبرُ الشعار «أسودُ الملف على الفاتح،
وأبيضُه على الداكن»، والذهبُ ‎`#B9933A`‎. لا نسخةَ ثانيةً هنا تفترق عن الأصل.

## حدودٌ معلنة

- النموذجُ لا يختار أيَّ الصور تُنشر ولا يعرف من فيها: **راجِع كلَّ صورةٍ بعينك قبل النشر.**
- الغشاءُ خفيفٌ قصدًا؛ ومن أراد الصورةَ بألوانها كما هي كتب لها `"veil": 0`.
