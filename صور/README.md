# قالبُ صور إذكاء

**صورةُ اللقاء كما هي، وعليها هويّةُ إذكاء وحدها — بلا كلام.** لا عنوانَ على الصورة ولا وصفَ ولا تاريخ:
الكلامُ مكانُه نصُّ المنشور والتقريرُ المكتوب، والصورةُ تحمل العلامة.

ما يوضع على الصورة:

- **موجةٌ زجاجيّة** بلون الليل في أسفل الصورة، تُرى الصورةُ من خلالها مموَّهة، وحافّتُها خيطٌ ذهبيّ.
- **المعيّنُ الذهبيّ** (من الشعار نفسِه) على قمّة الموجة، بحلقةٍ رقيقة وتوهّجٍ خافت.
- **خطوطُ تموّج** فوق الموجة تهدأ وتتسطّح كلّما ارتفعت، كأنها تموّجٌ ينتشر من المعيّن.
- **حقلُ معيّناتٍ خافت** داخل الموجة تحت القمّة.
- **الشعار** (الحبرُ أبيض والذهبُ ذهب) داخل الموجة في الطرف الآخر.

## الاستعمال

```bash
cd صور
npm install                                  # مرّةً واحدة (Playwright)
# ضع الصور في content/photos/ واذكرها في ملف المحتوى، ثم:
node src/build.mjs content/liqa-1.json       # ← dist/<meta.file>/
node src/build.mjs content/liqa-1.json --only الأصل,عمودي
```

```json
{
  "meta": { "file": "اللقاء-الافتتاحي" },
  "formats": ["الأصل"],
  "photos": [
    { "src": "photos/liqa-1-01.jpg" },
    { "src": "photos/liqa-1-02.jpg", "focus": [0.6, 0.35] }
  ]
}
```

يخرج في `dist/<meta.file>/` ملفُّ ‎JPG‎ لكل صورةٍ ومقاس، و`القرارات.json` بما قرّره النموذجُ لكلّ صورة.

| المقاس | الأبعاد | متى |
|---|---|---|
| `الأصل` (الافتراض) | نسبةُ الصورة ودقّتُها (حتى ‎4096‎ عرضًا) | **كلّ المنصّات** — الصورةُ كاملةً لا يُقتطع منها شيء |
| `أفقي` | ‎2400×1350‎ | إكس · لينكدإن إن أُريد ‎16:9‎ بالضبط |
| `عمودي` | ‎1080×1350‎ | منشور إنستغرام ‎4:5‎ |
| `قصة` | ‎1080×1920‎ | القصص · سناب شات (الشعارُ فوق ما تغطّيه واجهتُها) |

المقاساتُ غيرُ `الأصل` **تقتطع** من الصورة؛ والصورةُ العريضة في المقاسين العموديّين تفقد طرفًا لا محالة — فراجِعها.

## ما يقرّره النموذجُ وحده

1. **كم يُعتَّم فوق الموجة؟** يُقاس سطوعُ الشريط الذي يلي الموجةَ وزحامُه، فيشتدّ التعتيمُ على الصورة الفاتحة
   ويخفّ على الداكنة (بين ‎0.18‎ و‎0.62‎) — فتبقى الموجةُ والتموّجُ ظاهرين على كلّ صورة.
2. **كم يُصحَّح الضوء؟** مدُّ المستويات حول وسط الصورة نفسِها بسقف ١٢٪: تتوحّد سلسلةٌ صُوّرت بأكثر من آلة،
   ولا تُصبغ صورةٌ بلونٍ ليس فيها، ويبقى الداكنُ داكنًا.
3. **أين الموضوع؟** (للمقاسات المقتطَعة وحدها) خريطةُ حدّة: ما في بؤرة العدسة حادٌّ (المتحدّث والشاشة) وما
   خارجها ضبابيّ، فيُقتطع النطاقُ الذي يحمل أكثرَ الحدّة فوق الموجة، ويقترب ما دام لا يفقد من الموضوع أكثرَ
   من ٣٪. و`focus: [س، ص]` (من ٠ إلى ١) يتقدّم على الحساب إن أخطأ، و`zoom` تكبيرٌ مكتوب.
4. **المقاييس بنسبة الصورة**: الموجةُ والشعارُ والخطوطُ تُقاس بضلع الصورة الأقصر، فتتناسب في كلّ نسبةٍ ودقّة.

## الهويّة

كلُّ لونٍ من [`../عروض/src/brand.mjs`](../عروض/src/brand.mjs) وكلُّ شكلٍ من الشعار نفسِه
([`../عروض/src/identity.mjs`](../عروض/src/identity.mjs) ← `Logo.tsx`) — لا نسخةَ ثانيةً هنا تفترق عن الأصل.
والقواعدُ قواعدُ الهيئة: الذهبُ نادرٌ فيُرى (حافّةُ الموجة ومعيّنُ قمّتها وذهبُ الشعار)، والشعارُ مرّةً واحدة.

## حدودٌ معلنة

- الاقتطاعُ الذكيّ يفترض صورةً ذات بؤرة (وهو حالُ صور اللقاءات غالبًا)، ولا يتعرّف الوجوه.
- النموذجُ لا يختار أيَّ الصور تُنشر، ولا يعرف ما في الصورة من أشخاص: **راجِع كلَّ صورةٍ بعينك قبل النشر.**
