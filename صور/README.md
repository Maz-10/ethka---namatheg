# قالبُ صور إذكاء — ثلاثةُ أنماط

**الصورةُ كاملةً من الحافّة إلى الحافّة، وعليها الهويّةُ وحدها — بلا كلام.** والأنماطُ الثلاثة تشترك في «الذكاء»
(اختيارُ أهدأ زاوية، وشدّةُ الظلّ، والمستويات)، ويختلف كلٌّ منها في كيف تحلّ الهويّةُ على الصورة:

| النمط | الملف | الفكرة |
|---|---|---|
| **`تموج`** (الافتراض) | `src/frame.mjs` | الشعارُ في الزاوية، ومن معيّنه الذهبيّ تنتشر حلقاتٌ على شكله: الأولى ذهبيّةٌ تحيط بالرمز، ثم لؤلؤيّةٌ تبهت وتتباعد وتلتفّ على حوافّ الصورة، وتخفت قبل موضوعها. وصدى حلقاتٍ في الزاوية المقابلة. |
| **`زجاج`** | `src/glass.mjs` | معيّناتُ الرمز الثلاثة كبيرةً، ألواحُ زجاجٍ مُصنفَر تموّه ما خلفها — السفليّان بلون الليل والعلويُّ ذهبيّ — تدخل من الزاوية وتُقصّ عند الحافّة، واسمُ «إذكاء» داخل المعيّن الداخليّ. |
| **`قصة`** | `src/cut.mjs` | زاويةٌ من الصورة مقصوصةٌ على شكل المعيّن (قُطرٌ مائل برأسين مدوّرين كرؤوس المعيّن نفسِه)، مملوءةٌ بليل الهويّة، على حدّها خيطٌ ذهبيّ، والشعارُ فيها. |

## الاستعمال

```bash
cd صور
npm install                                 # مرّةً واحدة (Playwright)
# ضع الصور في content/photos/ واذكرها في ملف المحتوى، ثم:
node src/build.mjs content/liqa-1.json                     # النمطُ الافتراضيّ (تموج)
node src/build.mjs content/liqa-1.json --style زجاج
node src/build.mjs content/liqa-1.json --style تموج,زجاج,قصة # الثلاثة
```

```json
{
  "meta": { "file": "اللقاء-الافتتاحي", "style": "تموج" },
  "photos": [
    { "src": "photos/liqa-1-01.jpg" },
    { "src": "photos/liqa-1-02.jpg", "corner": "أعلى-يسار", "veil": 0.7 }
  ]
}
```

ويخرج مع الصور `القرارات.json` بما قرّره النموذجُ لكلّ صورة ولماذا (درجاتُ الزوايا الأربع).

## ما يقرّره النموذجُ وحده

1. **الزاوية**: تُرسم خريطةُ حدّة (ما في بؤرة العدسة حادٌّ وما خارجها ضبابيّ)، ويُحسب مركزُ ثقل الموضوع، ثم تُختار
   الزاويةُ الأقلُّ حدّةً والأبعدُ عنه، بميلٍ خفيف إلى الأسفل. و`corner` يتقدّم على الحساب:
   `أسفل-يمين` · `أسفل-يسار` · `أعلى-يمين` · `أعلى-يسار`.
2. **قناعُ الموضوع** (في التموّج): الحلقاتُ تخفت قبل أن تبلغ ما في البؤرة (المتحدّث والشاشة) فلا تمرّ على وجه؛ ولا تمرّ تحت
   اسم «إذكاء» في الشعار فيُقرأ صافيًا.
3. **شدّةُ الغشاء**: تُقاس سطوعُ الزاوية فيشتدّ الظلُّ على الفاتح ويخفّ على الداكن (بين ‎0.66‎ و‎0.9‎). و`veil` يتقدّم.
4. **المستويات**: مدٌّ خفيف حول وسط الصورة نفسِها بسقف ١٢٪.
5. **المقاييس بنسبة الصورة**: الشعارُ والحلقاتُ تُقاس بضلع الصورة الأقصر، والمخرجُ بدقّة الأصل (حتى ‎4096‎) بلا قصّ.

## الهويّة

كلُّ لونٍ من [`../عروض/src/brand.mjs`](../عروض/src/brand.mjs) وكلُّ شكلٍ من الشعار نفسِه
([`../عروض/src/identity.mjs`](../عروض/src/identity.mjs) ← `Logo.tsx`): الذهبُ ‎`#B9933A`‎، والليلُ ‎`#12171E`‎،
والحبرُ «أبيضُ الملف على الداكن». لا نسخةَ ثانيةً هنا تفترق عن الأصل.

## حدودٌ معلنة

- خريطةُ الحدّة تفترض صورةً ذات بؤرة (متحدّثٌ واضح وجمهورٌ ضبابيّ). في الصورة الحادّة كلِّها قد تمسّ أطرافُ
  الحلقات الخافتة الموضوع؛ فاكتب `corner` أو راجِع.
- النموذجُ لا يتعرّف الوجوه ولا يختار أيَّ الصور تُنشر: **راجِع كلَّ صورةٍ بعينك قبل النشر.**
