# صفحة رسم سير العمل — `سير-العمل/`

رابطٌ يُرسَل إلى العميل، فيرسم فيه مهمةً واحدة من عمل إدارته مرحلةً مرحلة، ويخرج بخريطتها وأرقامها وتصوّرٍ أوليّ لتحويلها.
المرجعُ: «إذكاء: صفحة رسم سير العمل — المواصفات وبرومبت البناء» (١٨ نوفمبر ٢٠٢٦).

**هذه المرحلة الأولى من البناء:** تجربةٌ كاملة بالقوالب وحدها، بلا ذكاء اصطناعي ولا خادم. الحفظُ في متصفّح العميل.

## التشغيل

```bash
cd سير-العمل && python3 -m http.server 8765    # ثم افتح http://localhost:8765/?جهة=اسم الجهة
node --test سير-العمل/test/calc.test.mjs        # اختبارُ الحساب على جدول القيم في المواصفات
```

صفحةٌ ساكنة بلا بناء ولا اعتماديات: تُرفع كما هي على أي استضافة.

| الملفّ | ما فيه |
|---|---|
| `js/data.js` | القوالبُ الثمانية للإدارة القانونية والخمسة العامة، وخياراتُ الخصائص، وجدولُ القيم — منقولةٌ من المواصفات |
| `js/calc.js` | الحساب، والانتقال بين الأيدي، وقواعدُ «بعد التحويل» — دوالُّ صافية مختبَرة |
| `js/store.js` | الحالة: حفظٌ تلقائيّ بعد كل لمسة، وتراجع. `persist()` نقطةُ الكتابة الوحيدة (ومنها يُزامَن مع الخادم لاحقًا) |
| `js/app.js` | الشاشات والتفاعل |
| `css/app.css` | الهوية: ألوانُ `عروض/src/brand.mjs`، وخطّا ثمانية، والطباعة |

## ما بقي للمراحل التالية
- **الثانية:** الخادم، والروابط الخاصة لكل جهة، ولوحة الفريق، والإرسال إلى زميل (مرحلةً أو مهمة).
- **الثالثة:** الترتيب الذكي للحكاية والتفريغ الصوتي. وحتى ذلك تُحفظ الحكاية ويُعرض أقربُ قالب (وهو البديلُ عند الإخفاق في المواصفات).
- **الرابعة:** ملفُّ ‎PDF‎ مولَّد في الخادم بدل طباعة المتصفح.
