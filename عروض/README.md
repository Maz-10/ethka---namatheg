# هيئةُ عروض إذكاء

**القالبُ الأصليّ لكلّ عرضٍ تقديميّ.** المحتوى يتغيّر من عرضٍ إلى عرض، والنموذجُ ثابتٌ لا يُعاد بناؤه:
يُكتب ملفُّ محتوى، فيُركَّب على الهيئة كما هي. وإن احتاج عرضٌ شكلًا لا يوجد، أُضيف **نوعٌ جديد** بالقواعد
نفسِها — ولا يُعدَّل نوعٌ قائم، ولا يُرسم قالبٌ من الصفر.

| الملفّ | ما هو |
|---|---|
| [`template/إذكاء-هيئة-العروض.potx`](template/) | **قالبُ باوربوينت**: أحدَ عشرَ تخطيطًا بأسمائها العربية («إذكاء ◆ …») وثمانيَ عشرةَ شريحةً نموذجيّة |
| `template/إذكاء-هيئة-العروض.pptx` | العيّنةُ نفسُها عرضًا عاديًّا |
| `template/إذكاء-هيئة-العروض.pdf` | معاينةٌ تُفتح في أيّ جهاز (الخطوطُ مضمَّنة فيها) |
| `content/specimen.json` | محتوى العيّنة — **وهو المثالُ الذي يُنسخ لكل عرضٍ جديد** |
| `src/` | المولِّد: الرموز · الهويّة · التخطيطات · أنواعُ الشرائح · التشطيب · الحارس |

## قبل فتح الملفّ: ثبّت خطَّي ثمانية

القالبُ مكتوبٌ بخطّ **ثمانية** وحده (`thmanyah sans` للمتن و`thmanyah serif display` للعناوين).
ملفّاتُهما في [`fonts/`](fonts/) — ثبّت الملفّات الثمانية مرّةً على الجهاز.
**لا يمكن تضمينُهما داخل ملف باوربوينت** (هما بصيغة CFF، وباوربوينت لا يضمّن إلا TrueType)، فبلا تثبيتٍ
يعرض باوربوينت خطًّا بديلًا وتتزحزح الأسطر. ولمن لا يملك الخطّين: ملفُّ ‎PDF‎ يُعرض كما صُمّم.

## طريقان للاستعمال

### ١) المولِّد — الطريقُ المعتمد

```bash
cd عروض
npm install                                   # مرّةً واحدة
cp content/specimen.json content/my-deck.json # ثم اكتب محتواك فيه
npm run deck -- content/my-deck.json --out out
npm run check                                 # جزمُ ما لا يُرى بالعين
```

يخرج `out/<meta.file>.pptx`. ثم **راجِع الشرائح صورةً صورة** قبل التسليم (الأمرُ في «المراجعة» أدناه).
ولإعادة بناء القالب نفسِه بعد تعديل الهيئة: `npm run build`.

### ٢) باوربوينت يدويًّا

افتح ‎`.potx`‎ (فيُنشئ عرضًا جديدًا منه)، ثم: **شريحة جديدة ← اختر تخطيطًا «إذكاء ◆ …»** فتجد الخلفيّة
والزخرفة وخاناتِ النصّ بأنماطها، والكتابةُ من اليمين افتراضًا، والنقطةُ معيّنٌ ذهبيّ. والشرائحُ المركّبة
(أرقام، بطاقات، رسم، مراحل، مقارنة) تُنسخ من العيّنة وتُحرَّر نصوصُها؛ والرسومُ أصيلةٌ تُحرَّر بياناتُها
من باوربوينت نفسِه.

## عقدُ المحتوى

```json
{
  "meta": { "file": "اسم-الملف", "title": "عنوان العرض", "short": "سطرُ التذييل", "numerals": "ar" },
  "slides": [ { "type": "cover", "...": "..." } ]
}
```

- `numerals`: ‏`ar` (مشرقيّة — الافتراض، كافتراض المنصّة) أو `en`. يسري على كل نصٍّ وعلى أرقام الرسوم.
- **ما بين علامتَي \`** يبقى كما كُتب (رمزُ لون، أمرٌ، مسار) ويُعزل اتّجاهُه فلا تقفز «#» أو النقطة.
- **المتغيّرات** تُقرأ من الرموز فلا يذكر نصٌّ رقمًا يفترق عن حقيقته: `{{layouts}}` · `{{types}}` ·
  `{{type.title}}` (أيُّ مقاسٍ في سلّم الطباعة) · `{{color.gold}}` (أيُّ لونٍ في الهويّة).
- `notes` في أيّ شريحة: ملاحظاتُ المتحدّث.
- **الوسم** فوق عنوان أيّ شريحة يتبع القسمَ الجاري إن لم يُكتب، و**الفهرس** يُشتقّ من فواصل الأقسام إن لم
  تُكتب بنودُه — فعنوانُ القسم يُكتب مرّةً واحدة.

| النوع | الحقول | متى |
|---|---|---|
| `cover` | `eyebrow` · `title` · `lead` · `meta: [{label, value}]` | الغلاف — الشعارُ بحضوره الكامل مرّةً واحدة |
| `agenda` | `title` · `items?: [{title, text}]` | الفهرس |
| `section` | `title` · `lead` | فاصلُ قسم: رقمٌ كبير ومسارُ الأقسام معيّنات |
| `statement` | `text` · `lead` | رسالةٌ واحدة تستحقّ شريحة |
| `points` | `title` · `lead?` · `points: [{title, text}]` (٤ بحدٍّ أعلى) · `aside?: {kicker, value, unit, title, label, text}` | استنتاجٌ وأدلّتُه، وبطاقةُ دليلٍ واحدة |
| `text` | `title` · `body: [..]` | متنٌ حرّ بنقاطٍ معيّنة |
| `stats` | `title` · `stats: [{value, unit, label, text, highlight}]` (٢–٤) · `note?` · `source?` | أرقامٌ كبيرة، وواحدٌ مُبرَزٌ بالذهب |
| `chart` | `title` · `chart: {kind: bar·column·line·doughnut, categories, series: [{name, values}], highlight, format}` · `takeaway: {title, points}` · `source` | رسمٌ أصيل + «ما يعنيه» |
| `table` | `title` · `columns` · `rows` · `widths?` · `align?` · `highlightRow?` · `note?` | جدولٌ من اليمين، وصفٌّ مُبرَز |
| `timeline` | `title` · `steps: [{label?, title, text, state?: done·now·next}]` (٣–٦) | مراحلُ ومسار |
| `cards` | `title` · `cards: [{title, text, swatch?}]` (٢–٦) | بطاقاتٌ في صفٍّ أو شبكة |
| `compare` | `title` · `primary` · `secondary` (`{kicker, title, items}`) | عمودان غيرُ متساويين: الموصى به والبديل |
| `image` | `title` · `text` · `image` (مسارٌ نسبيّ لملف المحتوى) · `caption` · `alt` | صورةٌ تنزف من الحافّة |
| `quote` | `text` · `name` · `role` | اقتباسٌ على الليل |
| `closing` | `title` · `steps: [..]` · `contacts: [{label, value, latin}]` | القرارُ المطلوب والخطوةُ التالية |

`highlight` في الرسم: رقمُ الفئة المُبرَزة في سلسلةٍ واحدة، أو رقمُ السلسلة بين سلاسل (افتراضُه الأخيرة)،
أو الشريحةُ في الحلقة (افتراضُه الأولى، ورقمُها في قلب الحلقة). `format` صيغةُ أرقامٍ إكسليّة (`0"%"`).

## قواعدُ الهيئة

**كلُّ قيمةٍ من مصدرها في المستودع** (`src/brand.mjs` يذكر مصدرَ كل لون):

| الدور | اللون | المصدر |
|---|---|---|
| الليل: الغلاف والفواصل والاقتباس والختام | `#12171E` | ملفّا ترويسة الهويّة · `--bg` الداكن |
| الكريميّ: سطحُ شرائح المحتوى | `#F4F1EA` | ملفّا ترويسة الهويّة · `--bg` |
| الورق: البطاقات | `#FDFCF8` | `--surface` |
| الحبر · وثانويُّه | `#232830` · `#5F6672` | `--ink` · `--ink2` |
| ذهبُ الشعار: المعيّنُ والأشكال | `#B9933A` | `اقرأني.txt` في حزمة الهويّة |
| ذهبُ النصّ على الفاتح | `#7E6029` | `--accent2` (الذهبُ الأصليّ ‎2.5:1‎ على الكريميّ فلا يُكتب به نصّ) |

- **الشعارُ والرمز يُقرآن من [`app/src/components/Logo.tsx`](../app/src/components/Logo.tsx)** ويُرسمان أشكالًا
  متجهيّةً أصيلة داخل باوربوينت (لا صورًا): حادّةٌ في كل مقاس، وحبرُها بلون سطحها. **ولا يُعاد رسمُهما.**
- **الشعارُ في الغلاف والختام وحدهما.** والمعيّنُ الذهبيّ هو التوقيعُ المتكرّر: وسمٌ فوق العنوان، ونقطةُ قائمة،
  ومحطّةُ مسار، ورقمٌ مُبرَز. **الذهبُ نادرٌ فيُرى** (نحو ٣٪ من السطح — قاعدةُ النسبة في تحليل الهويّة).
- **سلّمُ الطباعة** (`TYPE`): غلاف ٥٠ · قسم ٤٤ · عنوانُ شريحة ٣٠ · رقمٌ كبير ٥٢ · متن ‎15.5‎ · تذييل ١١.
- **فكرةٌ واحدة لكل شريحة، والعنوانُ استنتاجٌ** يُقرأ وحده لا اسمُ موضوع؛ وثلاثُ نقاطٍ إلى أربع بحدٍّ أعلى.
- **ما يُتجنّب**: لونٌ أو خطٌّ من خارج الهويّة · شريطٌ لونيّ أو خطٌّ تحت العنوان · الشعارُ في كل شريحة ·
  نصٌّ بالذهب الأصليّ على الفاتح · توسيطُ المتن.

## إضافةُ نوعٍ جديد

دالّةٌ في `RENDER` داخل `src/slides.mjs` تأخذ `(ctx, s)` وتبني على تخطيطٍ قائم (`L.TITLE` غالبًا)،
بالرموز من `brand.mjs` والمكوّنات من `kit.mjs` (`T` · `diamond` · `card` · `hair` · `footer`) — لا لونَ ولا
مقاسَ مكتوبٌ في الدالّة. ثم مثالٌ له في `content/specimen.json` (الحارسُ يرفض نوعًا بلا مثال)، ثم
`npm run build` و`npm run check` والمراجعةُ البصريّة.

## المراجعة

```bash
npm run check                                            # بنيةُ الملفّ: السمة · الاتجاه · الشعار · الخانات
soffice --headless --convert-to pdf out/my-deck.pptx     # ثم تُفحص الصفحاتُ صورةً صورة
```

ما لا يجزمه الحارس ويُرى بالعين: نصٌّ يفيض عن صندوقه، أو سطرٌ يتيم، أو كتلةٌ تزاحم أخرى.

## حدودٌ معلنة

- **الأسطرُ تُقدَّر ولا تُقاس**: ما تحت العنوان يجري بقدر أسطره من مقاييس ثمانية المقيسة (ارتفاعُ السطر
  ‎1.25‎ من المقاس، ومتوسّطُ عرض الحرف الموصول) بهامش أمان — فالمراجعةُ البصريّة شرط.
- **التحقّقُ البصريّ جرى بمحرّك LibreOffice** لا بباوربوينت نفسِه (غيرُ متاحٍ في بيئة البناء)؛ والملفُّ يجتاز
  فاحصَ البنية. والأرقامُ المشرقيّة في الرسوم بصيغة إكسل `[$-2000401]` (رمزُ أشكال الأرقام العربيّة).
- **رقمُ الشريحة نصٌّ يكتبه المولِّد** بالأرقام المختارة (أرقامُ حقل الترقيم الآليّ تتبع إعداداتِ الجهاز لا
  الهيئة)؛ فمن أضاف شريحةً يدويًّا عدّل رقمها.
- ترخيصُ الخطّين: وجودُهما في المستودع لا يثبت حقَّ توزيعهما خارجه (`docs/brand/assets/README.md`).

## في مستودع النماذج

هذه نسخةٌ من الطقم الأصليّ في مستودع المنصّة (`mezan/presentation-kit`) تعمل وحدها: الشعارُ يُقرأ من
`identity/Logo.tsx` (نسخةٌ مُودَعة من `app/src/components/Logo.tsx`) والخطوطُ في `fonts/`. إذا تبدّل الشعارُ
أو الهيئةُ هناك نُقلت النسخةُ إلى هنا كما هي — لا تُعدَّل هنا وحدها فيفترق النموذجان.
