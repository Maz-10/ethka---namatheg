# نماذج إذكاء — بطاقة دعوة «اللقاء الافتتاحيّ» لمجتمع إذكاء

نموذج البطاقة **بلا اسم** في `dist/template.pdf` و`dist/template.png` (مقاس A5).
والتصميم على فلسفة «المَجمَع الساكن» (`الفلسفة-المجمع-الساكن.md`): مخطّط مدرّجٍ من معيّن إذكاء نفسِه،
مقاعدُه باهتة إلا مقعدَ المدعوّ الذهبيّ في الصفّ الثاني، والرمزُ على المنصّة.

## التوليد

```bash
npm i playwright            # مرّةً واحدة
node build.cjs                                              # النموذج: dist/card.pdf · dist/card.png
NAME="الاسم الكامل" TOKEN=<مفتاح الردّ> OUTNAME=invite node build.cjs   # بطاقةٌ شخصيّة
```

- **رابط المكان** يفتح Google Maps (دبل تري — المركز المالي).
- **زرّا الردّ**: في البطاقة الشخصيّة يذهبان إلى `https://ethka.sa/rsvp/<TOKEN>` (تأكيد الحضور/الاعتذار) فيُسجَّل
  الردّ ويُنبَّه بريدُ إذكاء؛ وفي النموذج بلا اسم يذهبان إلى صفحة اللقاء ونافذة تسجيله.
- مفاتيح الردّ ومستقبِلها في مستودع الموقع (`site/src/data/invites.ts` · `site/worker/index.js`).

الخطوط: ثمانية (Thmanyah) من أصول إذكاء، وJura (OFL).
